# Getting Started

This page is an example documentation page that walks through getting a
project running locally. Replace this content with real instructions for
your own project.

## Prerequisites

- [Node.js](https://nodejs.org/en/download/) version 18.0 or above
- [npm](https://www.npmjs.com/) (bundled with Node.js)

## Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/danielwang/n1-ds-docs.git
cd n1-ds-docs
npm install
```

## Running locally

Start the local development server:

```bash
npm start
```

This opens a browser window at `http://localhost:3000/` and reloads
automatically as you edit files.
