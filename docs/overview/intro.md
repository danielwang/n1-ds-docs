# Introduction

Welcome to the **N1 DS Docs** documentation site. This is the documentation
landing page — the entry point for everything you need to know about the
project.

Use the sidebar on the left to browse the available topics, or jump straight
into one of the guides below.

## What you'll find here

- **Getting Started** — install prerequisites and run the project locally.
- **Guides** — task-oriented, example documentation pages that show how
  content is organized and written in Markdown.

## How this documentation is organized

Documentation pages live in the `docs/` directory as plain Markdown (`.md`)
files. The sidebar is generated automatically from that folder structure, so
adding a new page is as simple as creating a new Markdown file — see
"Adding Documentation Pages" in the project README for details.

Continue to [Getting Started](./getting-started.md) to begin.
