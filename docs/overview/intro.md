# Introduction

Welcome to the **nebulaONE** documentation site. This is the documentation
landing page — the entry point for everything you need to know about the
design system.

Use the sidebar on the left to browse the available sections, or jump
straight into one of the pages below.

## What you'll find here

- **Overview** — this section; start here for orientation and setup.
- **Foundations** — core design principles like color, typography, and
  spacing.
- **UI Components** — individual component documentation.
- **Design Tokens** — the named values that back the design system.

## How this documentation is organized

Documentation pages live in the `docs/` directory as plain Markdown (`.md`)
files, grouped into subfolders — one per sidebar category. The sidebar is
generated automatically from that folder structure, so adding a new page is
as simple as creating a new Markdown file — see "Adding Documentation Pages"
in the project README for details.

Continue to [Getting Started](./getting-started.md) to begin.
